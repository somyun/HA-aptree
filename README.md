# HA-aptree

Home Assistant에서 **아파트리(APTREE)** 입주민 계정의 아파트 관리비를 조회하는 비공식 커스텀 통합입니다.

아파트리 웹사이트에 앱과 같은 계정으로 로그인해 최신 관리비, 전기·수도 사용량, 동일 면적 세대 비교, 최근 12개월 상세 내역을 센서로 제공합니다.

> [!IMPORTANT]
> 이 프로젝트는 비케이위너 또는 아파트리의 공식 제품이 아닙니다. 웹사이트 구조가 변경되면 일시적으로 작동하지 않을 수 있습니다. 관리비 납부나 계정 변경 같은 쓰기 작업은 수행하지 않습니다.

## 제공 센서

- 총 관리비와 납부기한
- 미납액과 연체액
- 동일 면적 세대 평균·최저·최고 관리비
- 전기 사용량과 요금
- 수도 사용량과 요금
- 음식물쓰레기 요금
- 관리비 상세 항목
- 최근 12개월 관리비 상세 항목과 전기·수도·음식물쓰레기 추이
- 전기·수도 사용량 및 요금의 동종 세대 평균

금액 센서는 원 단위 정수로 표시되며, 기기 화면에서는 `1. 금액`, `2. 사용량`, `3. 기타` 순서로 모아 볼 수 있습니다. `12개월 관리비 추이` 센서의 `monthly_details` 속성은 월별 상세 관리비와 전기·수도 사용량을 포함해 대시보드에서 사용할 수 있습니다. 아파트리 웹사이트가 동일 면적 평균은 최신 월만 제공하므로 과거 평균값을 임의로 채우지는 않습니다.

월별 상세 내역은 Home Assistant의 통합 전용 영구 저장소에 누적됩니다. 통합은 저장된 자료만으로 즉시 시작되며, 최초 수집은 Home Assistant 부팅이 완전히 끝난 뒤 90초 후 시작합니다. 최신 월을 먼저 받고 이후 30초 간격으로 누락된 월을 한 달씩만 받아 매 단계 즉시 저장하므로 최근 12개월이 채워지는 데에는 보통 몇 분이 걸립니다. 네트워크 요청과 HTML 파싱은 모두 HA 이벤트 루프 밖의 작업 스레드에서 실행됩니다. 각 단계는 65초로 제한되며 실패하면 기존 저장 자료를 유지한 채 다음 정기 갱신까지 중단합니다. 최초 수집 후에는 하루에 한 번 최신 고지월을 확인하고 저장되지 않은 새 월만 추가합니다. Home Assistant를 재시작하거나 아파트리 웹사이트가 일시적으로 응답하지 않아도 마지막으로 저장된 내역은 계속 제공됩니다.

## HACS로 설치하기

### 1. 저장소 추가

1. Home Assistant에서 **HACS**를 엽니다.
2. 우측 상단 메뉴(점 3개)에서 **사용자 지정 저장소**를 누릅니다.
3. 저장소 주소에 `https://github.com/somyun/HA-aptree`를 입력합니다.
4. 유형은 **통합(Integration)** 을 선택하고 **추가**를 누릅니다.

### 2. 다운로드

1. HACS에서 **APTREE**를 검색합니다.
2. **다운로드**를 누릅니다.
3. 다운로드가 끝나면 Home Assistant를 다시 시작합니다.

### 3. 계정 연결

1. **설정 → 기기 및 서비스 → 통합 구성요소 추가**로 이동합니다.
2. `APTREE` 또는 `아파트리`를 검색합니다.
3. 아파트리 관리비 페이지 주소에서 **단지 번호**를 확인합니다. 예를 들어 `/home/user/6745/cac.php`의 단지 번호는 `6745`입니다.
4. 단지 번호와 아파트리 앱/웹에서 사용하는 **아이디와 비밀번호**를 입력합니다.
5. 로그인이 확인되면 APTREE 기기와 관리비 센서가 자동으로 생성됩니다.

카카오 계정만으로 로그인하고 별도의 아파트리 비밀번호가 없는 계정은 현재 지원하지 않습니다.

## 단지 번호, 아이디 또는 비밀번호 변경

1. **설정 → 기기 및 서비스 → APTREE**를 엽니다.
2. **구성**을 누릅니다.
3. 새 단지 번호, 아이디 또는 비밀번호를 입력합니다.

아이디만 유지하고 싶다면 그대로 두면 됩니다. 비밀번호 입력란을 비워 두면 기존 비밀번호가 유지됩니다. 저장 전에 새 계정 정보로 실제 로그인이 가능한지 확인합니다.

## 수동 설치

1. 이 저장소의 `custom_components/aptree` 폴더를 Home Assistant 설정 폴더의 `custom_components/aptree`로 복사합니다.
2. Home Assistant를 다시 시작합니다.
3. **설정 → 기기 및 서비스 → 통합 구성요소 추가 → APTREE**에서 계정을 연결합니다.

## 개인정보와 보안

- 아이디와 비밀번호는 Home Assistant 구성 항목에 저장됩니다. 저장소나 YAML 파일에는 작성하지 마세요.
- 웹 로그인 세션 쿠키는 Home Assistant 실행 중에만 사용하며 로그에 출력하지 않습니다.
- 관리비 상세 센서와 12개월 추이 센서의 속성에는 금액 정보가 포함됩니다.
- 누적 월별 내역은 Home Assistant의 `.storage` 아래 통합 전용 저장소에 보관됩니다. 이 파일을 직접 편집하지 마세요.
- Home Assistant Cloud, 장기 통계, 백업을 사용하는 경우 해당 데이터의 보관 범위를 확인하세요.
- 진단 다운로드에는 아이디, 비밀번호, 토큰, 관리비 금액이 포함되지 않습니다.

## 문제 해결

### 로그인이 실패할 때

- 아파트리 웹사이트에서 같은 단지 번호, 아이디와 비밀번호로 로그인되는지 확인합니다.
- 카카오 로그인 전용 계정인지 확인합니다.
- 짧은 시간에 로그인을 반복하지 말고 잠시 후 다시 시도합니다.

### 센서가 갱신되지 않을 때

1. **설정 → 시스템 → 로그**에서 `aptree`를 검색합니다.
2. APTREE 통합 페이지에서 다시 로드를 시도합니다.
3. 계정 비밀번호가 변경되었다면 **구성**에서 새 비밀번호를 입력합니다.

민감정보 보호를 위해 문제를 제보할 때 Home Assistant의 원본 `.storage` 파일이나 인증 토큰을 첨부하지 마세요.

## 지원 범위

- Home Assistant 2024.8.0 이상
- 대한민국 아파트리 입주민 일반 아이디/비밀번호 계정
- 읽기 전용 관리비 조회
